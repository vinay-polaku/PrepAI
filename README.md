# PrepAI

PrepAI is an AI-powered interview preparation platform that analyzes job descriptions and generates:

- Role Analysis
- Key Skills
- Technical Interview Questions
- Behavioral Interview Questions
- Resume Recommendations
- Elevator Pitches

## Technologies Used

- HTML
- CSS
- JavaScript
- Ollama
- Gemma 4

## Features

- Job Description Analysis
- Skill Extraction
- Tailored Technical Questions
- Tailored Behavioral Questions
- Resume Optimization Suggestions
- Elevator Pitch Generator
- Saved Interview Plans

## Future Improvements

- Resume Upload & Match Analysis
- Mock Interview Mode
- AI Answer Evaluation
